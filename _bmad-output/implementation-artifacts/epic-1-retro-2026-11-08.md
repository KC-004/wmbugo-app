### Aggregate views

- **Architecture delta:** core stays free of React Native, Drizzle and op-sqlite imports (ESLint boundary rule, gate-tested in `scripts/test-gates.mjs`). Features read through `*Api` modules that call `getServices()`, and screens take the api as a prop so tests inject fakes. No cycle introduced that was found by import reading. **Clean.**
- **Duplication map:** five features each run their own `SELECT ... FROM profile` (`accountsApi`, `activityApi`, `addApi`, `homeApi`, `settingsApi`) and each picks columns slightly differently. Three test files copy a `fakeApi` and the `useWindowDimensions` mock (`add.test.tsx`, `transfer.test.tsx`, `home.test.tsx`, `shell.test.tsx`). Disposition: **defer** a shared `readProfile()` and a shared test kit; low risk now, grows with Epic 2.

It is the one candidate god-component (next: `SettingsScreen.tsx` 381, `OnboardingFlow.tsx` 326). **Defer** a split into `TransferFields` and `DetailsFields` before Epic 2 adds more fields.
- **Pattern divergence:** none found in naming, error handling or test structure; the copy catalogue test and the lint guards held across all 16 stories. `.gitattributes` already normalises line endings (an earlier suspicion of mixed endings was checked and dropped).

## Process lessons (session transcript read for these)

- **L1** The longest delays were tool friction, not design: shell heredocs and `node -e` quoting lost backslashes and backticks and failed whole commands several times; `python` is not installed; two stories needed a second pass to restore a file clobbered by a string-slice script (`RootNavigator.tsx`, story 1.14). Lesson: write patch scripts with the Write tool and keep edits anchored on a unique string.
- **L2** Device checks found what 400+ unit tests did not: header under the status bar (1.10), foreign keys off on the connection (1.12), Save hidden under the keypad (1.13). Lesson: keep a device check in every UI story's definition of done, and screenshot at least once.
- **L3** The user can tap on the phone but `adb input` is blocked (no `INJECT_EVENTS`), so every UI check needed the human. Lesson: an emulator or an instrumentation test would remove the dependency and allow the p95 and hardware-key checks.
- **L4** All 16 stories were self-reviewed. Lesson: the 16 stories need one independent pass before `done`; this retro is the first.
- **L5** Stacked branches (each story from the last) made the history clean but any story fix after a later story exists needs a rebase chain. Lesson: fix-forward on the top branch, or merge the stack before more work.
