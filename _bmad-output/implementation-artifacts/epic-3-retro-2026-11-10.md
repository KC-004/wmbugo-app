# Epic 3 retrospective: Activity, find, fix and check (2026-11-10)

Verdict: accepted with open items. All 13 stories are built, committed locally (stacked branches, nothing pushed) and were checked on the Redmi phone as they landed.

## What went well

- Every story ended with core tests, mobile tests, lint and a phone check; totals at close: core 491 tests, mobile 952 tests.
- The single capture pipeline (`SubmitCapture`) held: refunds, transfers, entries and the tombstone skip all go through it, and an architecture test guards it.
- Exact Undo through `TxSnapshot` made reversible actions cheap to build and test.
- The independent review found real defects (15 fixed), mostly at the seams between stories: reversal versus delete, refund versus edit, purge versus held duplicates.

## What to change

- Seam tests should be written when a status or event type is added (`reversed`, `reversal`, `excluded`): every query and every use case that lists statuses needs an owner. Add a checklist item to the story template.
- Snapshots that hold only ids (attachments) cannot undo a deletion; prefer storing what a merge or purge drops in the undo data.
- Keep native and tooling checks early: the Device Guard block on `pnpm` and `hermesc` cost a round trip, and the gate script still needs a way to run without `pnpm`.
